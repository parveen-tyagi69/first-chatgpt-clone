# ChatGPT Clone (HTML + CSS)

A simple frontend clone of ChatGPT built using only HTML and CSS. This project focuses on layout and design without responsiveness or JavaScript logic.

## 🚀 Features

- Clean ChatGPT-like interface
- Static layout using Flexbox/Grid
- Custom header and input area
- Designed for desktop view only (non-responsive)

## 📌 Note

This is a **frontend-only** clone made for learning purposes — it has no backend or chatbot functionality.
